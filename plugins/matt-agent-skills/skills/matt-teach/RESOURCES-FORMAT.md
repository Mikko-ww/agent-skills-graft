# RESOURCES.md 格式

`RESOURCES.md` 是本主题可信来源的策展集合。解释性内容的 knowledge 应从这里抽取，而非 parametric 猜测。Wisdom 来自这里列出的 communities。

## Structure

```md
# {Topic} Resources

## Knowledge

- [Book: _The Science and Practice of Strength Training_ by Zatsiorsky & Kraemer](https://example.com)
  关于编程与适应的基础文本。Use for: periodisation、恢复、强度分区相关。
- [Article: "How Much Should I Train?" by Greg Nuckols (Stronger By Science)](https://example.com)
  关于训练量地标的证据综述。Use for: 每周每肌群组数目标。

## Wisdom (Communities)

- [r/weightroom](https://reddit.com/r/weightroom)
  高信噪比 subreddit，抑制 bro-science。Use for: 计划点评、平台期排查。
- Local: 周二 {健身房名} 力量课
  Use for: 动作的实时教练反馈。
```

## Rules

- **仅高信任。** 优先 primary sources、公认专家、同行评议工作、以及强 moderation 的 communities。若资源是伪装成教育的营销，剔除。
- **每条都加注释。** 光秃链接三个月后无用。加一行：覆盖什么、何时取用。
- **按 Knowledge / Wisdom 分组。** 与 [SKILL.md](./SKILL.md) 中的哲学对齐。资源只出现在一组也可以。
- **显式标出缺口。** 若 mission 需要的某领域没有好资源，写 `## Gaps` 列出缺失。这驱动后续搜索。
- **无情修剪。** 证明错误、肤浅或偏离 mission 的资源应删除，不要埋藏。五份锋利来源胜过三十份平庸。
- **记录 community 偏好。** 若用户选择不加入 communities，记在这里，避免未来会话反复提议。
