# GLOSSARY.md 格式

`GLOSSARY.md` 是本教学工作区的规范语言。所有解释、练习与 learning records 都应遵守其术语。构建它本身也是学习的一部分：把概念压成紧定义，是用户理解它的证据。

## Structure

```md
# {Topic} Glossary

{一两句描述本 glossary 覆盖的主题。}

## Terms

**Hypertrophy**:
由机械张力与代谢压力在重复训练会话中驱动的肌肉生长。
_Avoid_: Bulking, getting big

**Progressive overload**:
随时间系统性地提高对肌肉的需求，经由 load、volume 或 intensity。
_Avoid_: Pushing harder, levelling up

**RPE (Rate of Perceived Exertion)**:
对一组训练费力程度的 1–10 自评，10 为力竭，8 表示还能再做两次。
_Avoid_: Effort score, intensity rating
```

## Rules

- **仅在用户理解后加入术语。** Glossary 是压缩知识的记录，不是用户用来学习的词典。若概念刚介绍，等用户能正确使用后再提升到这里。
- **有主见。** 同一概念有多个词时，选最好的一个，其余列为应避免的别名。这就是语言如何压缩。
- **定义要紧。** 一两句。定义术语**是什么**，不是它做什么或如何做。
- **在定义内使用 glossary 自身术语。** 一旦术语入册，处处优先使用，包括其他定义内部。这使后期复杂术语更易把握。
- **出现自然聚类时用子标题分组**（例如 `## Anatomy`、`## Programming`）。术语本身连贯时，扁平列表即可。
- **显式标注歧义。** 若某术语在更广领域用法松散，记下本工作区的决议：「在本工作区，'set' 始终指 working set；热身单独追踪。」
- **理解加深时修订。** 用户第一周写的定义到第六周可能已错。原地更新；不要留下过期条目。
