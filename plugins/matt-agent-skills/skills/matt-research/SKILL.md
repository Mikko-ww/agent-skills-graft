description: 对着高可信 primary sources 调查问题，并把发现写进仓库里的一份 Markdown。在用户要调研某主题、收集 docs / API 事实、或把阅读苦力委派给后台子代理 / 并行 worker 时使用。
invocation: model
---

启动一个 **后台子代理 / 并行 worker** 做调研，使你能在它阅读时继续工作。

它的工作：

1. 对着 **primary sources**（官方文档、源代码、规格、第一方 API）调查问题，而不是对着它们的二手转述。把每条主张追溯到拥有它的源头。
2. 把发现写入单一 Markdown 文件，并为每条主张引用来源。
3. 存到仓库已有此类笔记的位置；匹配既有约定；若没有约定，放到合理位置并说明放在哪。
